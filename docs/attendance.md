# Посещаемость в личном кабинете

В разделе «Успеваемость» показываются отметки только того студента, которого администратор связал с аккаунтом. По умолчанию выбран текущий месяц по времени Тюмени; месяц можно переключить стрелками или выбрать в календаре.

Сводка считает только явно поставленные отметки: был, прогул, болезнь, уважительная причина, работа и заявление. Пустая ячейка не означает пропуск. Удалённые отметки и скрытые пары исчезают после передачи обновлённой недели. Оценки колледжа пока не подключены.

## Передача из админки

После входа по обычному паролю своей роли откройте «Посещаемость». История выбранного курса передаётся автоматически. Новые отметки передаются после успешного сохранения в исходном зашифрованном репозитории. Кнопка «Обновить ЛК» повторяет передачу всей истории курса, не создавая повторных сохранений отметок.

Статус передачи в ЛК показан отдельно от статуса сохранения. Если сервис ЛК недоступен, сохранённые в админке отметки остаются на месте. Повторите передачу кнопкой. Для сессий, открытых до этого обновления, может понадобиться выйти и войти в админку снова, чтобы получить ограниченный доступ к передаче посещаемости.

## Защита данных

Приватный источник расшифровывается в браузере админки. API принимает минимальную копию отметок недели без ключа GitHub, ключа шифрования и ФИО. Администратор, староста и куратор получают отдельный токен только для посещаемости. Этот токен не даёт доступа к управлению аккаунтами.

Перед чтением каждой недели сервер выдаёт одноразовый билет, связанный с сессией, курсом и неделей. Его порядок не позволяет запоздавшей передаче заменить более свежие данные. Студентский API определяет личность по HttpOnly cookie, проверяет актуальную привязку и активный список студентов при каждом чтении. API не кэшируется офлайн.

## Проверка

`npm test` проверяет SQLite и Postgres (PGlite), HTTP-доступ, роли, изоляцию студентов, снятие привязки, отчисление, повтор билетов, порядок передач, границы месяцев и состояния интерфейса.

Для локальной проверки браузером: `node scripts/preview-attendance.mjs`. Стенд работает только на `127.0.0.1:4193` с временной базой в памяти и вымышленными отметками. Тестовый вход: `qa_student` / `qa-student-only`. Он не использует производственную базу.
