# ТКПСТ Расписание

Android-приложение с расписанием пар группы **ИС-25-3С** (ТКПСТ, Тюмень).

## Что умеет (этап 1)

- Главный экран: «Расписание» и «Автобусы».
- Дни недели Пн–Сб сверху, стрелки на прошлую/следующую неделю. При открытии выбран сегодняшний день.
- Пары: номер, предмет, время, кабинет, преподаватель, замены.
- Перерывы между парами (10 мин, большие 25/30/40 мин, «окна»), классные часы по понедельникам (8:00 и 14:00).
- Живые таймеры на сегодняшний день: «начнётся через…», «закончится через…» с полоской прогресса, «перерыв закончится через…».
- Всё время — по Тюмени (`Asia/Yekaterinburg`, UTC+5), независимо от пояса телефона.
- Офлайн: последнее загруженное расписание сохраняется на телефоне.
- Тема: как в системе / светлая / тёмная (Настройки).

## Автобусы (этап 2)

- Домашний адрес: ввод с подсказками (OpenStreetMap) или «определить по GPS». Хранится только на телефоне.
- Вкладки «В колледж» / «Домой» (Луначарского, 19). Вкладка выбирается сама: до конца сегодняшних пар — «В колледж».
- Остановки в радиусе ~1 км, маршруты без пересадок и с одной пересадкой (пешком до 500 м).
- Сортировка: «Меньше в пути» (по умолчанию) или «Раньше приеду». Одинаковые пути с разными номерами склеены («или №54, 85»).
- Время прибытия — онлайн по GPS автобусов (api.tgt72.ru, Тюменьгортранс), обновление каждые 30 с; если прогноза нет — по графику с пометкой.
- «Ближайшие автобусы» на 2–3 остановках рядом.
- Сеть маршрутов скачивается раз в день (~10 с) и перезаписывает один файл — размер не растёт.

## Уведомления

Фоновая синхронизация (раз в ~4 часа) присылает уведомление, когда вышло расписание на новые дни или изменились пары.

## Источники данных

- Пары: [OpenScheduleApi](https://github.com/ThisIsHyum/OpenScheduleApi), сервер `https://api.thisishyum.ru/schedule_api/tyumen`
  (тот же, что использует [osa.vstor-tech.ru](https://osa.vstor-tech.ru)). Группа ИС-25-3С — id 196.
- Время пар и перерывов — официальное «Расписание звонков» (`Bells.kt`), а не время из API.

## Сборка

APK собирается автоматически в GitHub Actions на каждый push в `main`:
- **Releases** → последняя «Сборка N» → `tkpst-schedule-N.apk` (удобно скачивать с телефона);
- или **Actions** → последний запуск → Artifacts.

Локально: Android Studio → Open → эта папка (или `gradle assembleDebug`).

## Структура

```
app/src/main/java/ru/yami/tkpst/
  data/Bells.kt              звонки с фото, часовой пояс Тюмени
  data/Timeline.kt           пары + классные часы + перерывы, формат таймеров
  data/ScheduleRepository.kt запросы к API и кэш
  ui/ScheduleScreen.kt       экран расписания с таймерами
  ui/HomeScreen.kt, BusesScreen.kt, SettingsScreen.kt
```
