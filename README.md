# ТКПСТ Расписание

Приложение для **Android и iPhone** с расписанием пар группы **ИС-25-3С** (ТКПСТ, Тюмень) и автобусами Тюмени.

## Сайт для iPhone (без установки)

**https://wtfhoshi.github.io/tkpst-schedule/** — открой в Safari → «Поделиться» → «На экран „Домой“».
Откроется с ярлыка как приложение: расписание с таймерами, автобусы онлайн, тёмная тема, работает без сети (последнее расписание).
Код — папка `web/` (без сборки), публикуется на GitHub Pages при каждом push.

## Что умеет (этап 1)

- Главный экран: «Расписание» и «Автобусы».
- Дни недели Пн–Сб сверху, стрелки на прошлую/следующую неделю. При открытии выбран сегодняшний день.
- Пары: номер, предмет, время, кабинет, преподаватель, замены.
- Перерывы между парами (10 мин, большие 25/30/40 мин, «окна»), классные часы по понедельникам (8:00 и 14:00).
- Живые таймеры на сегодняшний день: «начнётся через…», «закончится через…» с полоской прогресса, «перерыв закончится через…».
- Всё время — по Тюмени (`Asia/Yekaterinburg`, UTC+5), независимо от пояса телефона.
- Офлайн: последнее загруженное расписание сохраняется на телефоне.
- Тема: как в системе / светлая / тёмная (Настройки).

## Автобусы (этап 2)

- Домашний адрес: ввод с подсказками (OpenStreetMap) или «определить по GPS». Хранится только на телефоне.
- Вкладки «В колледж» / «Домой» (Луначарского, 19). Вкладка выбирается сама: до конца сегодняшних пар — «В колледж».
- Остановки в радиусе ~1 км, маршруты без пересадок и с одной пересадкой (пешком до 500 м).
- Сортировка: «Меньше в пути» (по умолчанию) или «Раньше приеду». Одинаковые пути с разными номерами склеены («или №54, 85»).
- Время прибытия — онлайн по GPS автобусов (api.tgt72.ru, Тюменьгортранс), обновление каждые 30 с; если прогноза нет — по графику с пометкой.
- «Ближайшие автобусы» на 2–3 остановках рядом.
- Сеть маршрутов скачивается раз в день (~10 с) и перезаписывает один файл — размер не растёт.

## Админ-панель (староста, куратор, администратор)

`https://wtfhoshi.github.io/tkpst-schedule/admin/` — правка расписания поверх данных колледжа:
дистант, отмена пары, замена (предмет/кабинет/преподаватель), новая пара, своё расписание на день
(если сайт колледжа не работает), заметка к дню и объявление для всех.

- Вход по паролю — тем же, что и в «Посещаемость» (администратор, староста, куратор); один вход на обе вкладки.
- Сохраняет закрытый сервер `attendance-api/` (Netlify): он хранит ключ GitHub (подключается один раз со страницы
  админки; нужен fine-grained token на `tkpst-schedule` с правом **Contents: Read and write**) и правит файл сам.
  В истории коммитов видно, кто сохранял: «Админ (Староста): …».
- Панель записывает `web/overrides.json` в репозиторий → GitHub Pages обновляет сайт за 1–3 минуты.
- Сайт, Android и iOS скачивают `overrides.json` сами (при открытии и в фоне) — обновлять приложения не нужно.
  Об изменениях на будущие дни приходит уведомление.
- Прошедшие дни удаляются из файла автоматически при сохранении.

## Посещаемость (в админ-панели, только для своих)

`https://wtfhoshi.github.io/tkpst-schedule/admin/#att` — вкладка «Посещаемость» рядом с «Изменением расписания».

- Группа везде ИС-25-3С. 1 / 2 / 3 курс → месяц → неделя → день (на телефоне) или вся неделя таблицей (на компьютере).
- Пары берутся из реального расписания ИС-25-3С; кнопка «Пары» — добавить или убрать любую пару в любой день.
- Отметки: ✓ был, Н — неуважительная причина, Б — болеет, У — уважительная, Р — работает, З — по заявлению.
  Выбираешь «кисть» внизу и нажимаешь на клетки; повторное нажатие стирает. «Остальные ✓» отмечает всех, у кого пусто.
- Excel: неделя, месяц или весь курс — цвета, легенда, итоги по каждому студенту (пропуски, часы, % посещаемости).
  Файл открывается в Google Таблицах (Файл → Импорт → Загрузка).
- Вход по паролю: администратор и староста — всё (отметки, Excel, студенты, группы курсов, загрузка старой таблицы),
  куратор — отметки, Excel и список студентов.
- Данные лежат на закрытом сервере Netlify (`attendance-api/`, Netlify Functions + Blobs) — **не в этом репозитории**,
  поэтому сайт расписания и приложения Android/iOS их не видят. Пароли — в переменных окружения Netlify
  (`ATT_PASSWORD_ADMIN`, `ATT_PASSWORD_KURATOR`, `ATT_PASSWORD_STAROSTA`, `ATT_SECRET`).

## Уведомления

Фоновая синхронизация (раз в ~4 часа) присылает уведомление, когда вышло расписание на новые дни или изменились пары.

## Источники данных

- Пары: [OpenScheduleApi](https://github.com/ThisIsHyum/OpenScheduleApi), сервер `https://api.thisishyum.ru/schedule_api/tyumen`
  (тот же, что использует [osa.vstor-tech.ru](https://osa.vstor-tech.ru)). Группа ИС-25-3С — id 196.
- Время пар и перерывов — официальное «Расписание звонков» (`Bells.kt` / `Bells.swift`), а не время из API.

## Сборка

GitHub Actions на каждый push в `main` собирает обе версии и кладёт их в **Releases → «Сборка N»**:
- `tkpst-schedule-N.apk` — Android;
- `tkpst-schedule-N.ipa` — iPhone (без подписи, для AltStore / SideStore).

Локально: Android — Android Studio → Open → эта папка. iOS — `cd ios && xcodegen generate`, открыть `Tkpst.xcodeproj` в Xcode.

## Установка на iPhone (AltStore, бесплатно)

1. На компьютере (Windows или Mac) установи **AltServer** с [altstore.io](https://altstore.io) и через него поставь **AltStore** на iPhone (понадобится Apple ID; на Windows — iTunes и iCloud с сайта Apple).
2. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID. На iOS 16+ включи «Режим разработчика» (Настройки → Конфиденциальность и безопасность).
3. На iPhone открой в Safari страницу **Releases**, скачай `tkpst-schedule-N.ipa`, нажми «Поделиться» → **AltStore** (или в AltStore: My Apps → «+» → выбрать файл).
4. Бесплатная подпись живёт 7 дней: AltStore продлевает её сам, когда iPhone и компьютер с AltServer в одной Wi‑Fi сети (или нажми Refresh All).

Обновление: скачай новую `.ipa` и поставь так же — данные и адрес сохранятся.

Особенности iOS: фоновое обновление расписания запускает сама iOS (обычно раз в несколько часов, если приложение открывали недавно). В остальном — всё как на Android.

```
  data/Bells.kt              звонки с фото, часовой пояс Тюмени
  data/Timeline.kt           пары + классные часы + перерывы, формат таймеров
  data/ScheduleRepository.kt запросы к API и кэш
  ui/ScheduleScreen.kt       экран расписания с таймерами
  ui/HomeScreen.kt, BusScreen.kt, AddressScreen.kt, SettingsScreen.kt
  data/transit/Router.kt     поиск маршрутов (прямые + 1 пересадка)
ios/
  project.yml                проект XcodeGen
  Core/                      Swift-пакет: звонки, перерывы, маршруты + тесты
  App/Sources/               SwiftUI-экраны, API, кэш, уведомления, GPS
```
